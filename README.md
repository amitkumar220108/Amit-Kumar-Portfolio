# 💻 Personal Portfolio Website

A modern, responsive and animated personal portfolio website built to showcase my education, technical skills, projects, achievements and contact information.

## 🌐 About the Project

This portfolio represents my academic journey, technical interests and development experience as a Computer Science student.

It features a clean dark-themed design with purple and blue accents, smooth animations and responsive layouts for different screen sizes.

## ✨ Features

- Modern and responsive user interface
- Dark and light theme toggle
- Animated typing effect
- Page loading animation
- Smooth scroll and reveal animations
- Interactive navigation bar
- Technical skills section
- Education and achievements section
- Project showcase with GitHub links
- Contact form with email integration using FormSubmit
- Back-to-top button
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- FormSubmit (Contact Form Integration)

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.

## 📩 Contact Form

The contact form is integrated with FormSubmit to receive messages through email.

To configure it for your own portfolio:

1. Replace the email address in `script.js` with your email.
2. Submit a test message through the contact form.
3. Verify your email using the activation link sent by FormSubmit.
